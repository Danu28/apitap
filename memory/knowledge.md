# Knowledge — ApiTap

Project facts the pipeline relies on:
- Extension layout (v1.1): manifest v3 with ACTION POPUP (popup.html/popup.js) as the only UI — DevTools panel and devtools_page are GONE. Capture source is chrome.debugger (CDP Network domain) attached to the active tab, wired in background.js (service worker). utils/debugcapture.js is the pure CDP-event→apiCall mapper (dual-exported, Node-tested).
- DevTools constraint GONE: capture runs on the recording tab via chrome.debugger regardless of DevTools being open. Chrome shows a 'debugging' bar while recording. Opening DevTools on the recording tab detaches the debugger → onDetach stops recording gracefully. Popups close on page interaction — recording continues in the SW; the popup resyncs on open via GET_SESSION.
- Permissions: debugger (full page access on the recorded tab — the honest price of body capture), downloads, storage, unlimitedStorage. NO host_permissions needed for debugger capture.
- MV3 gotchas: SW may die anytime → all handlers await ensureSessionLoaded(); session persisted to chrome.storage.local key 'apitapSession'; unlimitedStorage granted; persistSession try/catch'd (in-memory fallback).
- request.ts for captured calls = request START (CDP wallTime converted), not finish.
- Engine (utils/correlation.js, class still named ApiTapCorrelator): EVERY captured call is stored; noise calls (filterReason != null) start checked:false + noiseReason (their responseBody is null — base64 images/media would balloon the session); burst-dedupe still drops repeats; groupKey = METHOD|host|pathname (query/hash dropped; malformed → 'unparseable'); setChecked(id|groupKey, bool); groups() derived Map; getStats {calls, groups, filtered (stored-noise count), deduped}; serialize/mergeState (checked defaults: noise→false, others→true).
- Noise (utils/filter.js): telemetry domains matched EXACT or subdomain-only (host === d || endsWith('.'+d)) — never substring (junk entries '1stdibs'/'qquared'/'crashtrace'/'gtag' and dead '/'-entries purged); '.js' IS in ASSET_EXTENSIONS; filterReason() = 'telemetry'|'asset-extension'|'asset-content-type'|'no-url'|null; isNoise = filterReason !== null (order: telemetry → extension → content-type).
- snapshot (GET_SESSION) derives groupKey per call — popup renders, never recomputes grouping itself.
- Exporter (utils/postman.js): buildCollection filters checked!==false, one folder per groupKey (label "METHOD /path"), {{baseUrl}} from most-common origin, DROP_HEADERS incl. cookie (stale session state — never exported), body never truncated (a cut body would replay wrong data; README caps only response bodies at 200KB, marker appended there). URL objects are Postman-native: raw ({{baseUrl}}-substituted) + protocol/host[]/path[]/query params/hash/variable[] parsed from the concrete URL. Structured auth (bearer/basic) derived from the Authorization header; item-level response: []. Collection variable type must be 'string' (v2.1 enum) — 'default' is schema-invalid.
- Export is JSON-schema-validated against https://schema.postman.com/json/collection/v2.1.0/collection.json (fetch to /tmp, ajv-draft-04, NODE_PATH=C:/Users/dhanu/node_modules due to npm prefix quirk).
- Panel: one pane, no tabs; group row = checkbox (indeterminate when mixed) + method badge + path + count + expand; export button disabled when nothing checked; SESSION_UPDATED re-fetch debounced 200ms.
- Test entry: `node apitap.test.js` (root). No framework — assert + exit code. CI: .github/workflows/test.yml runs it on push/PR (node 22, ubuntu). Timings in tests must space calls > 1500ms or burst-dedupe swallows them.
- Guardrail (2026-09-03 audit): 0 unused exports — the UMD util wrappers export only what background/tests consume (no isStaticAsset/TELEMETRY_DOMAINS/ASSET_EXTENSIONS/MAX_BODY_CHARS/commonOrigin, no stripTrackingParams — URLs are stored as captured).
- v1 survivors removed in v2: content.js, steps/variables machinery, token chaining, environment export. Re-add chaining later = re-introduce TOKEN_KEYS machinery + Postman authTestLines.
